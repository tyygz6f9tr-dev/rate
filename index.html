▶ 임대매장 유통수수료율 월별 현황 만들기

엑셀 파일을 올리면 월별 매출·신장률·수수료율 페이지를 만들어요. 파일은 서버로 전송되지 않고 이 브라우저 안에서만 처리돼요.

1. 파일 선택

필수 월별 판매현황 시트가 '1월', '2월' … 'N월'로 나뉜 파일. 각 시트의 실판금액(올해)과 비교(작년) 열로 매출·신장률을 계산해요. 선택된 파일 없음
필수 수금 파일 (임대매장 유통수수료율 월별누계) '1~N누계' 시트의 월별 유통수수료율과 N월 누계 수수료율을 가져와요. 주요매장은 코드 칸 초록색 칠 또는 '주요매장' 열 표시로 골라요. 선택된 파일 없음
선택 전년실적 (매출·수수료 RAW) '종합' 시트의 매장코드 · 매출 · % 열로 전년실적과 전년 수수료율 칸을 채워요. 없으면 비워둬요. 선택된 파일 없음

계산 규칙

  • 브랜드: 매장코드 첫 글자 S = 쉬즈미스, T = 리스트, A = 시스티나
  • 행사 매장: 매장명 앞에 (행)이 붙은 매장은 같은 브랜드에서 (행)을 뺀 이름이 같은 본 매장에 합산하고, 매장코드는 본 매장 코드를 써요. 예) T42017 (행)스타필드안성 → T42012 스타필드안성
  • 월별 신장률 = 그달 실판금액 ÷ 작년 같은 달 − 1 / 누계 신장률 = 1~N월 실판금액 합 ÷ 작년 1~N월 합 − 1
  • 월별 수수료율 = 수금 파일의 그달 유통수수료율 / 합계 수수료율 = 수금 파일의 N월 누계 값
  • 빨간 칸 = 수수료율 40% 이상
