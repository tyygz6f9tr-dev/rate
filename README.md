# 임대매장 유통수수료율 월별 현황 만들기

엑셀 파일을 올리면 「임대매장 유통수수료율 월별 현황」 페이지(월별 매출·신장률·수수료율)를 만들어 주는 웹 도구예요.
GitHub Pages에 올려두면 누구나 같은 주소에서 파일만 올려서 결과를 볼 수 있어요.
파일은 서버로 전송되지 않고 각자 브라우저 안에서만 처리돼요. 외부 라이브러리도 쓰지 않아요.

## 파일 구성

| 파일 | 역할 |
|---|---|
| `index.html` | 업로드 화면 (이 주소로 접속) |
| `app.js` | 계산 규칙 (행사 매장 합산, 신장률, 수수료율) |
| `xlsx-lite.js` | 엑셀(.xlsx) 읽기 (값 + 셀 초록색 칠 인식) |
| `template.html` | 결과 페이지 디자인 (기존 월별 현황 사이트와 동일) |
| `schema-check.js` | 컬럼 변경 확인 (전달 기준과 머리글 비교) |
| `schema.json` | 전달 기준 컬럼 목록 (2026년 1~9월 파일 기준) |

## 매달 사용하는 방법

1. 도구 주소(예: `https://<계정>.github.io/<저장소>/`)에 접속해요.
2. 파일 3개를 선택해요.
   - **월별 판매현황** (필수): 시트가 `1월`, `2월` … `N월`로 나뉜 파일. 각 시트의 `매장명 / 매장코드 / 실판금액 / 비교(…)` 열을 써요.
   - **수금 파일** (필수): `2026 (1~N누계)` 시트. 월마다 `매출 / 임대관리비 / 수금 / 유통수수료율` 열과 `N월 누계`, `1~N` 매출·수금 열을 써요. 시트는 자동으로 가장 최근 누계 시트를 골라요(바꿀 수 있어요).
   - **전년실적** (선택): 매출·수수료 RAW 파일의 `종합` 시트 (`매장코드 / 매출 / %`).
3. **현황 만들기**를 누르면 아래에 요약과 미리보기가 나와요.
4. **HTML 파일로 저장**을 눌러 결과 파일을 내려받아요.
5. 내려받은 파일 이름을 `index.html`로 바꿔서 저장소의 `2026-10/` 같은 월 폴더에 올리면
   `https://<계정>.github.io/<저장소>/2026-10/` 주소로 열려요. 이 주소를 게시판에 걸면 돼요.

## 컬럼 변경 확인

파일을 올리면 계산 전에 세 파일의 머리글(컬럼명)을 `schema.json`(전달 기준)과 비교해서
**추가 / 삭제 / 변경**된 컬럼을 파일 · 시트 · 열 위치별로 보여줘요.

- 계산에 꼭 필요한 컬럼(매장코드, 매장명, 실판금액, 비교, 코드, 계열, 매출, 수금, 유통수수료율, N월 누계, %)이 바뀌면 **필수**로 빨갛게 표시돼요.
- 컬럼명이 바뀌어 계산이 멈춰도 이 비교 결과는 먼저 보여줘서, 어디가 바뀌었는지 알 수 있어요.
- 매달 자연스럽게 바뀌는 표기는 변경으로 치지 않아요.
  `비교(2025-09)` → `비교(2025-10)`, `9월 누계` → `10월 누계`, `1~9` → `1~10`, 새로 생긴 `10월` 블록
- 수금 파일은 월 블록마다(1월, 2월 …) 안쪽 컬럼(매출 / 임대관리비 / 수금 / 유통수수료율)도 따로 비교해요.

**기준 바꾸기**: 바뀐 컬럼이 맞는 변경이면(그리고 계산이 잘 되면) **「이번 달 컬럼을 새 기준으로 저장」**을 눌러
`schema.json`을 내려받은 뒤, 저장소의 기존 `schema.json`을 덮어 올려주세요. 다음 달부터는 그 기준으로 비교해요.
계산에 필요한 컬럼 이름이 바뀐 경우에는 `app.js`의 컬럼 이름도 함께 고쳐야 해요.

## 계산 규칙

- **브랜드**: 매장코드 첫 글자 S = 쉬즈미스, T = 리스트, A = 시스티나
- **행사 매장 합산**: 매장명 앞에 `(행)`이 붙은 매장은 매장코드 첫 글자가 같은 브랜드에서 `(행)`을 뺀 이름이 같은 본 매장에 합산하고, 매장코드는 본 매장 코드를 써요.
  예) `T42017 (행)스타필드안성` → `T42012 스타필드안성`
- **주요매장**: 수금 파일에서 `주요매장` 열에 표시가 있으면 그 매장, 없으면 **코드 칸을 초록색으로 칠한 매장**을 써요.
- **월별 매출** = 그달 실판금액 (행사 합산)
- **월별 신장률** = 그달 실판금액 ÷ 작년 같은 달 실판금액 − 1
- **합계 매출** = 1~N월 실판금액 합
- **누계 신장률** = 1~N월 실판금액 합 ÷ 작년 1~N월 합 − 1
- **월별 수수료율** = 수금 파일의 그달 유통수수료율 (그달 매출이 있을 때만)
- **합계 수수료율** = 수금 파일의 `N월 누계` 값
- **브랜드·전체 총 수수료율** = 1 − (수금 합 ÷ 매출 합), 수금 파일 누계 기준
- **빨간 칸** = 수수료율 40% 이상

## GitHub Pages에 처음 올리는 방법

1. GitHub에서 새 저장소(Public)를 만들어요. 예: `rent-report`
2. **Add file → Upload files**로 위 4개 파일을 올리고 **Commit changes**를 눌러요.
3. 저장소 **Settings → Pages**에서 Source를 `Deploy from a branch`, Branch를 `main` / `(root)`로 고르고 **Save**를 눌러요.
4. 1~2분 뒤 `https://<계정>.github.io/rent-report/`로 접속하면 업로드 화면이 열려요.
